# The_Omniscience

## Что это?

The_Omniscience — это графическая оболочка рабочего стола для Windows 10 22H2,
построенная на Electron и React. Она сосуществует с нативной оболочкой
и не ломает её. Начинался проект как расширение для Google Chrome —
это была его зигота.

## Зачем он нужен?

Честный ответ: мы не знаем.

За всё время существования проекта ни один участник не смог сформулировать,
зачем он нужен. Мы не считаем это проблемой.

The_Omniscience существует потому, что он существует, и потому, что мы им
пользуемся каждый день. Если вы нашли для него применение — отлично,
расскажите нам. Если нет — вы не одиноки.

## Установка

1. Windows 10 22H2.
2. Установить Node.js.
3. Скачать проект.
4. Перейти в папку проекта.
5. Запустить `./install.bat`.

Всё.
