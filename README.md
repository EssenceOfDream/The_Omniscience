# The Omniscience

The Omniscience — графическая оболочка рабочего стола на Electron и React. Проект поддерживает Windows и Linux/X11. Интерфейс и большая часть документации — на русском языке.

## Установка и запуск в Windows

Для работы нужны Git, Node.js `20.19+` или `22.12+` и npm. В Windows стандартная оболочка Explorer остаётся включённой, а Omniscience запускается как обычное приложение при входе пользователя.

1. Склонируйте проект и установите зависимости:

   ```powershell
   git clone https://github.com/EssenceOfDream/The_Omniscience.git
   cd The_Omniscience
   npm install
   ```

2. Разместите проект вместе с `node_modules` в постоянной папке пользователя.
3. Запустите `install.bat`. Он устанавливает зависимости, включает верхнее положение панели задач Windows 10, отключает её автоскрытие через пользовательский реестр и регистрирует Omniscience в автозапуске:

   ```powershell
   .\install.bat
   ```

4. Запустите Omniscience. При необходимости приложение перезапустит Explorer, чтобы применить верхнее положение панели задач; открытые окна Проводника могут закрыться. Крестовина управления и панель Omniscience появятся под системной панелью.

Настройки панели задач сохраняются постоянно и не откатываются при выходе из Omniscience. Установка не меняет системную оболочку Winlogon и не требует прав администратора для регистрации автозапуска текущего пользователя.

Чтобы убрать Omniscience из автозапуска, выполните:

```powershell
npm run windows:setup:restore
```

Эта команда не меняет положение и автоскрытие панели задач. Для восстановления старой установки, которая ранее подменяла машинную оболочку, используйте из повышенного PowerShell:

```powershell
npm run windows:legacy-shell:restore
```

Вверху экрана панель Windows и крестовина управления наслаиваются слева; одна строка Omniscience начинается сразу справа от крестовины, непосредственно под панелью Windows. Крестовина занимает высоту верхнего ряда вместе со строкой Omniscience; приложение периодически возвращает её поверх панели Windows. На Windows собственный список окон Omniscience скрыт; окна переключаются с панели задач Explorer. При запуске приложение не скрывает и не перезапускает Explorer, не меняет обои и не принудительно перемещает окна других программ.

Кнопка «Параметры» открывает страницу Omniscience с переходами к классическим средствам Windows. Это обходной вариант для систем, где приложение «Параметры» недоступно, в частности Windows 10 Enterprise LTSC 2019.

## Linux

На Linux `npm start` запускает приложение Electron из терминала. Для установки и ручного запуска выполните:

```bash
git clone https://github.com/EssenceOfDream/The_Omniscience.git
cd The_Omniscience
npm install
npm start
```

Для полноценной отдельной X11-сессии нужны X11 и KWin (`kwin_x11`); настройка дисплейного менеджера и такой сессии выполняется отдельно. Поддержка Wayland ограничена, macOS не поддерживается.

## Возможности

- Рабочий стол с настраиваемым фоном, несколькими виртуальными рабочими столами и собственными окнами приложений.
- Верхняя панель с поиском, меню приложений и меню питания; в Windows список окон предоставляет панель задач Explorer.
- Управление внешними окнами Windows через Win32 и Linux/X11 через системный оконный менеджер.
- Встроенные приложения и подключаемые приложения из `componentapps/`.
- Файлы рабочего стола Windows: ярлыки `.lnk` из пользовательской и общей папки Public Desktop показываются вместе; при совпадении имён приоритет у пользовательского ярлыка.
- Приложения UWP/пакетные приложения Windows отображаются в списке программ и запускаются через Windows Activation Manager.
- На рабочем столе Windows `desktop.ini` читается как метаданные папки и не показывается отдельным файлом. Поддерживаются текстовые `LocalizedResourceName` и `InfoTip`, а также существующий `.ico`. Другие `.ini` отображаются как обычные файлы. Ссылки `@...` на ресурсы Windows не разрешаются.

## Разработка

Чтобы проверить существующие тесты:

```powershell
node --test tests\*.test.mjs
```

Чтобы добавить встроенное приложение, создайте каталог в `componentapps/`. Для него используются `Index.jsx` и `App.jsx`; при сборке Vite каталог приложения подхватывается автоматически. Дополнительные `ipc.js`, `preload.js` и `index.html` можно добавить по необходимости — см. существующие приложения в `componentapps/`.

Основная точка входа Electron — `index.mjs`. Она инициализирует пути и модули, загружает конфигурацию, собирает интерфейс и запускает рабочий стол и панель.

## Известные ограничения

- macOS не поддерживается; для Wayland доступна ограниченная функциональность.
- На Windows системное приложение «Параметры» может быть недоступно в LTSC; кнопка открывает встроенную страницу с переходами к классическим средствам.
- Встроенные сетевые меню Wi‑Fi/Bluetooth отсутствуют.
- Некоторые настройки `desktop.ini`, в том числе локализованные строки-ссылки на ресурсы `@...` и иконки из DLL/EXE, не обрабатываются.
- Некоторые функции и приложения могут зависеть от версии ОС, драйверов и установленного системного ПО.
